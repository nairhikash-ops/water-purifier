# AquaPure Solutions - Authorised Water Purification & Doorstep Service Hub

A modern, high-converting, fully functional web application tailored for water purifier distribution, sales, and multi-brand service.

---

## 🌟 Brand Positioning & Customer Trust

Rather than projecting a "middleman reseller" image, the website positions **AquaPure Solutions** as an **Authorised Multi-Brand Sales & Doorstep Service Partner**:
- **Direct Factory Pricing**: Passing savings directly to consumers without showroom overheads.
- **Authorised Quality Guarantee**: 100% Genuine NSF/CE certified components, food-grade ABS body, original membranes.
- **Complete On-Site Service**: Installation within 24-48 hours, free water TDS testing, and 1-year comprehensive warranty.
- **Pay After Installation**: Zero advance required, maximizing buyer confidence.

---

## 🌟 Key Features

1. **Direct Factory Product Catalog**:
   - Integrated with real inventory:
     - **Cloud International Aqua One 3 (Grey)**: 3-in-1 Copper + Zinc + Alkaline, Smart LED display.
     - **Purosis Puroaqua RO + Alkaline**: 100% Food Grade, Antimicrobial, 7-stage filtration.
     - **Aqua Next Pro (RO + Copper + Alkaline)**: 10L detachable storage tank with 5 color options.
     - **Merlin Planet Series**: Dual-tone design with solid copper dispensing tap.
     - **Commercial 50 LPH RO Plant**: Stainless steel skid for offices, cafes, clinics.
     - **Universal 1-Year Filter Spares Kit** & **Bio-Copper Retrofit Cartridges**.
   - Category filtering, dynamic instant search, TDS level filter, and price sorting.
   - Deep-dive product specification modal with full 7/8-stage breakdown and inside-the-box accessories.

2. **Instant WhatsApp Ordering & Pay on Installation / COD**:
   - Direct WhatsApp integration with pre-filled item specifications.
   - Slide-out Cart Drawer with item quantity counter, delivery address form, and zero-advance checkout.
   - Order confirmation with celebratory confetti and tracking reference (`ORD-XXXXXX`).

3. **Interactive Water Purifier Selector Quiz ("Find My Purifier")**:
   - 4-step wizard matching source, TDS levels, family size, and priority feature.

4. **Interactive Water TDS Quality Guide**:
   - Interactive PPM slider (50 to 2000 ppm) demonstrating water hardness, health impact, and recommended purification technology.

5. **Complete AMC & Doorstep Repair Booking Engine**:
   - Annual Maintenance Contract tiers: Silver, Gold (Most Popular), Diamond (100% Zero Expense).
   - One-time repair options: General service, filter change combo, leakage repair, shifting & re-installation.
   - Multi-brand service booking form with time slot selection.

6. **Free Doorstep Water TDS Test Lead Magnet**:
   - Lead capture form for homeowners to book a complimentary water test.

7. **Operations & Leads Hub (Staff/Admin Portal)**:
   - Click "Operations Portal" in the footer to inspect all customer orders, repair bookings, and water test requests.
   - One-click **"Export to CSV"** button to download leads directly into Excel.

## 🚀 Running the Project

The development server is running at:
```bash
http://127.0.0.1:3000/
```

To run manually at any time:
```bash
npm run dev
```

To create an optimized production build:
```bash
npm run build
```
