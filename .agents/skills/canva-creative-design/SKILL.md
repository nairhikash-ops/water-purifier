# Canva Creative Design & Visual Aesthetics System

This skill empowers Antigravity to craft world-class, high-converting visual assets using Canva and graphic design principles tailored for water purification, health, and vitality products.

---

## 1. Brand Visual Identity: The "Purity & Vitality" Aesthetic

When designing assets for **AquaPure Solutions**:

### Color Palette & Chromatic Harmony
- **Glacial Cyan / Aqua (`#0ea5e9`, `#38bdf8`, `#e0f2fe`)**: Evokes crystalline spring water, purity, freshness, and oxygenation.
- **Deep Marine / Navy (`#0c4a6e`, `#0f172a`)**: Establishes medical-grade authority, engineering trust, and reliability.
- **Ayurvedic Copper / Warm Bronze (`#c35817`, `#e0a96d`, `#fdf8f6`)**: Highlights natural copper infusion, ancient wellness, and immunity.
- **Vitality Emerald (`#10b981`, `#059669`, `#ecfdf5`)**: Signifies cellular health, antioxidant defense, and non-toxic safety.
- **Crisp Crystalline White (`#ffffff`, `#f8fafc`)**: Ample negative space to communicate sterility and pristine cleanliness.

### Typography Hierarchy
- **Primary Headlines**: Bold, modern sans-serif (Plus Jakarta Sans, Montserrat, Inter, Poppins) — strong, clear, authoritative.
- **Subheadings & Accents**: Medium weight sans-serif with generous letter-spacing.
- **Numbers & Metrics**: Extra-bold or black weight for statistics (e.g., **"pH 8.5+"**, **"99.8% Purity"**, **"₹0 Test"**).

## 3. Composition & Visual Hierarchy Rules

1. **The 3-Second Rule**: The viewer must understand the offer, the product, and the single primary benefit within 3 seconds.
2. **Focal Point Isolation**: Never clutter the canvas. 60% of the visual space should feature the product with glowing droplets or pure water refractions.
3. **Contrast for Legibility**: Never place light text over light backgrounds. Use dark overlay gradients (linear-gradient from dark navy to transparent) behind headlines.
4. **Authentic Imagery**: Always feature real, high-resolution product photography (e.g., Cloud Aqua One 3, Purosis Puroaqua, Merlin Planet, Aqua Next Pro).
5. **Clear Call-to-Action (CTA) Pill**: Include a distinct WhatsApp / Call action pill:
   - *"Order via WhatsApp • Pay on Installation"*
   - *"Book Free Doorstep Water Test Today"*

## 4. Canva MCP Server Tool Integration Guide

When using Canva MCP tools:
- Query existing templates with keywords like `water purifier`, `clean energy`, `health technology`, `wellness flyer`.
- Specify explicit brand color codes and font pairings.
- Ensure text layers do not overlap key product features (LED indicators, dispenser taps, tank gauges).
